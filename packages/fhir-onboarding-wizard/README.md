# FHIR Setup Wizard

# @opensrp/fhir-onboarding-wizard

This package provides a multi-step setup wizard for onboarding a new OHS Foundation deployment — creating the initial Location, Organization, Care Team, and Users as a single guided flow, backed by the fhir-care-team, fhir-team-management, and user-management packages.

## Installation

```sh
yarn add @opensrp/fhir-onboarding-wizard
```
